# Bayesian Optimization and Active Learning in Drug Discovery

Welcome to **bayesoptimol**, an interactive book on applying Bayesian optimization and active learning to molecular discovery. It aims to bridge the gap between theoretical machine learning concepts and their practical use in drug discovery through clear explanations and executable code examples.

## What You'll Find Here

- **Foundations**: Bayesian optimization, active learning, and how to represent molecules and reactions for machine learning
- **Gaussian Processes**: probabilistic surrogate models and kernels tailored to chemical space
- **Acquisition Functions**: balancing exploration and exploitation (EI, UCB, Thompson sampling)
- **Active Learning Strategies**: uncertainty, diversity, and expected-model-change sampling
- **Case Studies**: solubility, binding affinity, and multi-objective optimization
- **Implementations**: hands-on examples with scikit-learn, GPyTorch, and BoTorch
- **Advanced Topics**: batch, multi-fidelity, and constrained optimization

## How to Use This Book

Each chapter combines explanations with runnable Python code. Notebooks can be opened directly in Google Colab via the badge at the top of each notebook, so no local setup is required.
